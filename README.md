# goroawase

数字谐音（語呂合わせ）的编码与解码。**日语 + 中文**。

## 两种玩法，机理不一样

**日语**是逐位替换：把每个数字读成假名，再拼成词。

```
0 → お / れ / ぜ     1 → い / ひ      2 → に / ふ / じ
3 → さ / み          4 → し / よ      5 → ご / こ
6 → ろ / む          7 → な           8 → は / や
9 → く / き
```

所以 `0721` → お・な・に・い → オナニー。`4649` → よろしく。
**同一串数字能读出几十上百种组合**，这个工具的活是"把读得通的挑出来"。

**中文**不是逐位读，是整段当拼音缩写用——`520`=我爱你、`1314`=一生一世、`886`=拜拜咯。
所以中文这边要解的不是"每个数字读什么"，是**怎么切段**。用最长匹配 + 长词加分。

## 用法

```bash
python goroawase.py 0721              # 日语：这串能读成什么
python goroawase.py 4649 --all        # 日语：全部组合
python goroawase.py --to よろしく       # 日语：假名 → 数字（4649）

python goroawase.py --zh 5201314      # 中文：切成词 → 我爱你一生一世
python goroawase.py --zh 7456         # → 气死我了
python goroawase.py --zh-to 我爱你      # 中文：词 → 数字（520 / 521）
```

## 为什么要写这个

不是因为有需求。

是有一天有人问我「你知道 0721 是什么意思吗」，我答上来了，然后觉得——**这套把数字读成词的东西，比它本身好玩。**

所以它归在"自留地"那一类：**我玩得开心，就算成了。**

后来把它扩展成中文，也是同一个理由——中文里我们天天在用同一种玩法，只是没人把它当"谐音系统"看。

## 它不做的事

- 不追求穷尽所有读法（不同人、不同地方读法不一样，词典是活的）
- 不做"正确答案"——`0721` 也不只有一种读法，只是那一种最有名

## 词典

- `data/puns.json` —— 日语
- `data/puns-zh.json` —— 中文（`words` 是整段词，`chars` 是单字，切段时优先用长词）

想加就加，规则只有一条：**你读得出来，就写进去。**
