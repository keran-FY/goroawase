# goroawase

数字谐音（語呂合わせ）的编码与解码。

日语里有一整套玩法：把数字读成假名，再拼成词。比如 `0721` → お・な・に・い → オナニー。
`4649` → よ・ろ・し・く → よろしく。

**同一个数字串能读出几千种组合**，所以这个工具的活不是"查表"，是**把读得通的挑出来**。

```bash
python goroawase.py 0721          # 这个数字串能读成什么
python goroawase.py 4649 --all    # 列出全部组合
python goroawase.py --to よろしく     # 反查：这个词对应哪个数字 → 4649
```

## 为什么要写这个

不是因为有需求。

是有一天有人问我「你知道 0721 是什么意思吗」，
我答上来了，然后觉得——**这套把数字读成词的东西，比它本身好玩。**

所以它归在"自留地"那一类：**我玩得开心，就算成了。**

## 它不做的事

- 不追求穷尽所有读法（不同人、不同地方的读法不一样，词典是活的）
- 不做"正确答案" —— `0721` 也不只有一种读法，只是那一种最有名

## 词典

`data/puns.json`，键是数字串，值是读法（可以带注释）。
想加就加，规则只有一条：**你读得出来，就写进去。**
